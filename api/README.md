# ALU Back-End

This repository contains backend engineering projects, API integration tasks, and data manipulation scripts completed as part of the African Leadership University (ALU) software engineering curriculum.

## Projects & Directory Structure

* **`api/`**: Python scripts for interacting with RESTful APIs, parsing JSON data, and fetching records based on identifiers.
    * `0-gather_data_from_an_API.py`: Retrieves and displays employee TODO list progress from the JSONPlaceholder API using standard libraries.

## Requirements
* Python 3.x
* Built-in `urllib` and `json` modules
